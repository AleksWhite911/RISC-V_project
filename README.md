# Support instruction:
  1.  ADD
  2.  OR
  3.  SRL
  4.  SLTU
  5.  SUB
  6.  MUL
  7.  LW
  8.  SW
  9.  ADDI
  10. LUI
  11. AUIPC
  12. BEQ
  13. BNE
  14. JAL

# Available periphery:
  1. Two I/Q DDS
  2. 2 GPIO ports (32 bits)
